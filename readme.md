# Requirements
[Browser with WebGPU enabled](https://developer.mozilla.org/en-US/docs/Web/API/WebGPU_API#browser_compatibility) with these following features
- `immediate_address_space`. (Chrome >149, `#enable-unsafe-webgpu`)

Tested on Helium 0.13.6.1 (Chromium	149.0.7827.200, Linux) with `#enable-unsafe-webgpu` enabled. WebGPU is enabled by default on Windows.

You might need `#enable-vulkan` as it might use a fallback cpu renderer for some reason.
