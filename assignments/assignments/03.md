## cabin1: Salt-and-pepper noise

**ปัญหา:** มีจุดขาว/ดำกระจายทั่วภาพ (impulse noise) แต่ภาพเป็น JPEG ทำให้จุด noise บางส่วนเพี้ยนไปจาก 0/255 เล็กน้อย (เช่น 242, 13)

**วิธีที่ลอง:**
- `median_filter` 3x3 ลบ noise ได้ดีแต่ภาพเบลอทั้งภาพ เพราะเปลี่ยนทุก pixel
- `median_filter(adaptive=True)` (adaptive median) เก็บรายละเอียดได้ดีกว่า แต่จุด noise ที่ JPEG ทำให้เพี้ยนไม่ได้เป็น min/max ของ window พอดี จึงหลุดรอดไปเป็น "รายละเอียดปลอม"
- `impulse_median_filter`: ใช้ median แทนเฉพาะ pixel ที่มีค่า 0 หรือ 255 ส่วน pixel อื่นคงไว้ตามเดิม

**ผลลัพธ์ที่ดีที่สุด:** `impulse_median_filter(data, 3)` ง่ายแต่ได้ผลดี เพราะ salt-and-pepper noise มีค่าเป็น 0/255 อยู่แล้ว จึงไม่ต้องไปยุ่งกับ pixel ปกติ

## cabin2: Gaussian noise

**ปัญหา:** noise เม็ดละเอียดทั่วทั้งภาพ เป็น additive Gaussian noise (histogram เป็นรูประฆัง ความแรงเท่ากันทุกระดับความสว่าง) sd ≈ 30 ซึ่งแรงมาก

**วิธีที่ลอง:**
- `median_filter`, `gaussian_blur`, `geometric_mean_filter`: noise ลดแต่ขอบเบลอหรือเป็นปื้นๆ
- `wiener_filter` (adaptive local Wiener): เฉลี่ยบริเวณเรียบ คงขอบไว้ ได้ภาพสะอาดแต่นุ่ม ต้องกำหนด noise_var เอง
- blur → deconvolution และ Fourier lowpass: ไม่ช่วย เพราะ noise กระจายทุกความถี่ทับกับรายละเอียดของภาพ
- `non_local_means_filter`: เฉลี่ย pixel ที่ patch รอบๆ คล้ายกัน บ้านสะอาด แต่ป่ากลายเป็นภาพวาดสีน้ำ

**ผลลัพธ์ที่ดีที่สุด:** BM3D (`bm3d` package, sd = 23) หา patch ที่คล้ายกันแบบ NLM แล้วซ้อนเป็นก้อน 3D แปลงเป็น frequency domain และตัด coefficient เล็กๆ ที่เป็น noise ทิ้ง รายละเอียดที่ patch ในกลุ่มมีร่วมกันจึงรอด ผนังไม้ ประตู ราวระเบียงชัด ป่ายังมี texture

```python
out = bm3d.bm3d(data / 255, sigma_psd=23 / 255)
```

## stop_sign: Gaussian blur

**ปัญหา:** ภาพเบลอแบบ Gaussian (ประมาณ sigma ≈ 4 จากการลองหลายค่า)

**วิธีที่ลอง:**
- `inverse_deconvolution` (F = G / H): ใช้ไม่ได้ เพราะ H เกือบเป็น 0 ที่ความถี่สูง noise จึงถูกขยายจนภาพกลายเป็น noise ทั้งภาพ
- `unsharp_mask`: ขอบคมขึ้นเล็กน้อย แต่ไม่ได้แก้ blur จริง
- `wiener_deconvolution`: F = conj(H) / (|H|² + k) · G โดย k ช่วยกันไม่ให้ noise ระเบิด ได้ภาพคมพอสมควร (s=4, k=0.005) แต่มี grain และ halo จางๆ
- `tv_deconvolution` (Total Variation): หา f ที่ minimize ||blur(f) − g||² + λ·Σ|∇f| แก้ด้วย ADMM ใช้ L1 กับ gradient จึงชอบภาพที่เป็นพื้นเรียบ + ขอบคม ซึ่งตรงกับลักษณะของป้าย STOP

**ผลลัพธ์ที่ดีที่สุด:** `tv_deconvolution(data, sigma=4, lam=0.001)` ตัวอักษรคม พื้นสีแดงเรียบ ไม่มี ringing แต่พื้นหลัง (ต้นไม้ ถนน) กลายเป็นปื้นๆ เพราะ TV มองว่า texture เป็น noise

ถ้า sigma = 5 ทั้ง Wiener และ TV จะเริ่มมี halo แสดงว่าค่า blur จริงอยู่ราวๆ 4

## moon: Defocus blur

**ปัญหา:** ภาพถ่ายผ่านกล้องโทรทรรศน์ที่โฟกัสไม่ตรง ภาพเบลอทั้งดวง มี chromatic aberration (ขอบสีน้ำเงิน) แต่ noise น้อย

**วิธีที่ลอง:**
- `defocus_deconvolution`: Wiener deconvolution ด้วย PSF รูปวงกลม (disk) ซึ่งเป็นลักษณะของ blur จากการโฟกัสไม่ตรง ได้รายละเอียดเพิ่มขึ้นบ้างที่ r ≈ 5–6 แต่เกิดวง ringing ที่ขอบดวงจันทร์ (r ≥ 7 ยิ่งชัด)
- `unsharp_mask`: out = img + amount · (img − blur(img)) เพิ่ม contrast ที่ขอบ ไม่มี artifact

**ผลลัพธ์ที่ดีที่สุด:** `unsharp_mask(data, 15, 2)` ดูเป็นธรรมชาติที่สุด deconvolution ดึงรายละเอียดจริงได้มากกว่านิดหน่อย แต่ ringing ทำให้ภาพรวมแย่กว่า รายละเอียดที่ละเอียดกว่ารัศมี blur (~5–6 px) หายไปตั้งแต่ตอนถ่ายแล้ว จึงกู้คืนไม่ได้
